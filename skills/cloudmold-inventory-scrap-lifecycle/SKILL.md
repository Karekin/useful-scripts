# Inventory scrap lifecycle

Use the R3 task definition for evidence-backed scrap only. It creates and approves the scrap document, records physical disposal, posts the owning inventory-domain decrement, and closes the document with frozen versions and independent actors. Direct balance edits are forbidden.
