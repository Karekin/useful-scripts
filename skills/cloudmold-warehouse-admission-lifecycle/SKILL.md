# 入仓决策主流程

## 业务目标

把“是否允许进入平台仓、由哪个商家承接、采购和入仓是否完成、履约是否可验证、质检通过后的流量如何承接”收敛为一个供应链岗位主流程。

## 执行阶段

1. 创建、通知并认领入仓决策行动单。
2. 直接回读商品的消费者质量证据；只有 `VERIFIED + COMPLETED + PASS` 才继续。
3. 招商运营完成全新 BD 商家与店铺的建档、审核、激活和终态验收。
4. 为质检通过的规范 SKU 完成寻源、采购下发、平台仓收货、调拨、出库、盘点和库存验收。
5. 以质检通过和平台仓履约完成作为站内活动触达的证据来源，执行质量流量承接并回读投放终态。
6. 三条业务链全部成功后关闭行动单并回读 `RESOLVED`。

## 失败语义与权威边界

- 缺少质量证据、质量被拒绝或召回时直接失败，不允许入仓。
- Merchant、Procurement、WMS、Quality 分别保留各自事实权威；行动单只记录跨域决策证据。
- 当前流量动作由站内 Engagement 活动承接，不冒充外部广告平台的预算、竞价或结算权威。
