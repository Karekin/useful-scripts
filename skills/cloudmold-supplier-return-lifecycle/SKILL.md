# Supplier return lifecycle

Use the R3 task definition against accepted, rejected, or quarantined canonical receipt evidence. It creates, submits, independently approves, dispatches, and completes the return before the finance domain posts the reversal. All source versions, quantities, valuation evidence, accounting policies, and actors must be frozen in the input.
