# 渠道/KOL 媒体合作运营闭环

这是岗位级经营主动脉，不是报表查询、投放读数或单点方法调用。

每日由 Temporal 生成全新的合作案例，并在 R3 审批后执行：

1. 建立候选合作案例并完成风险准入、触达与 brief 提交/批准。
2. 生成当次新品并完成真实商品刊登与触达投放。
3. 绑定新品创建合作内容，完成内容提交、品牌/合规批准、外部发布与披露校验。
4. 以真实消费者身份完成选购、支付履约、售后和社区链路，产出真实订单与支付结果。
5. 使用真实子流程返回的 `orderId` 与 `paymentId` 完成归因、结算批准、付款确认与关单。

只有内容披露、归因和结算三个终态都达成，合作案例才能关闭。
