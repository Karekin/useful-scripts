# 报告与数据草案

每份报告封面必须包含报告期、数据截至、数据来源与刷新状态。数据不足、来源不可验证或刷新异常时显式显示 `UNKNOWN/STALE`，不可填 0 或推断成功。

## 1. 九部分报告

1. 准入标记总览。
2. 品牌集中度：排除品类 Top20 与 Top3 品牌。
3. 热力图：准入后品类月 GMV 与覆盖。
4. 渠道分布：三渠道占比、聚集度与卖法分类。
5. 发展现状：已覆盖、纺织类缺失、优先推荐。
6. 产地城市招商指引：Top5 城市与聚集/分散策略。
7. 优先级矩阵：六维评分及逐项来源。
8. 专项分析：羽绒/皮草等入仓成本，童装安全极高风险。
9. 月度坑位规划：Top30 品类、坑位和 GMV 目标；“12 月/12 个月”口径尚待确认，必须在封面和明细同时标记。

## 2. 七张核心数据表草案（未落地）

这是未来逻辑数据合同草案，不代表任何表、来源、BI 模型或访问权限已经接入。每张都需数据负责人确认字段、主键、分区、安全等级、刷新 SLA 和质量规则。

| 表/粒度 | 建议字段 | 候选来源 | 用途 | 假设与待确认 |
| --- | --- | --- | --- | --- |
| 大市场宽表 / 品类×日×渠道 | 类目、日期、渠道、GMV、订单、品牌 GMV、份额、退货率、数据截至 | 跨渠道聚合 | 市场规模、品牌集中、卖法 | 三渠道身份、GMV/退款口径和安全分区待定义。 |
| 商品维度 / SKU 或商品版本 | 商品、SPU/SKU、类目、材质、属性、上市/下市、版本 | Catalog 只读投影 | 属性/材质/F0/准入分析 | 规范 SKU 与外部商品映射未确认。 |
| 成交明细 / 订单行 | 成交时间、商品、金额、数量、渠道、退款/确认收货标记 | 交易事实 | GMV、退货、坑产 | BI 交易识别与确认收货定义待明确。 |
| CRM 订单 / 订单或客户交互 | 订单、客户分群引用、触达/反馈、时间 | CRM 只读事实 | 消费者/运营回读 | 隐私、用途与跨域可见性待定义。 |
| 卖家维度 / 商家版本 | 商家、产地、签约、高潜标记、履约状态、版本 | Merchant 只读事实 | 招商卡口 | 商家密度与高潜池定义待配置。 |
| 物流订单 / 履约单 | 订单、承运、时效、异常、签收、退回 | Fulfillment/Logistics 只读事实 | 履约/逆向证据 | 履约率公式与事件时点待定义。 |
| 品类策略与决策台账 / 品类×版本×周期 | 品类、策略/规则版本、准入结论、目标、交接、审批、证据摘要、状态 | Catalog 未来规范 SoR | 策略权威、审计、报告可重放 | 建议的第七张；尚无已接入持久化或 Outbox。 |

## 3. 不得补造的待定义项

- BI 交易识别、分区安全、均值、冬季 GMV、BCA 合并规则。
- 三渠道的精确名称、来源授权、刷新频率、主键和映射。
- 年度品类计划三段式分析的三个具体阶段。
- 八大部门名单、授权矩阵和准入评审的最终签字规则。
- 月度报告“12 月/12 个月”口径、市场规模 40 分分档、季节“其他”分档、供应商密度规则、完整 13 类特殊场景词典。
