# 品类管理生命周期与协作 SOP

## 1. 权威、状态与交接

Catalog 持有品类策略、类目规则、准入结论、周期计划和跨域交接记录。所有跨域请求必须指向接收域自己的受控能力；Catalog 只保留请求、批准、接收和只读验收引用。Quality 与 Supply Chain 对质量安全、入仓和履约风险具有**阻断/升级权**：其否决或未闭环升级会阻止品类开放或推进，不可被品类评分抵消。

`DRAFT → SCOPE_APPROVED → DIAGNOSED → PORTFOLIO_DECIDED → HANDOFF_READY → MONITORING → REVIEWED → {ACTIVE | REMEDIATION | EXITED}`。整改完成后必须回到 `REVIEWED`；`ACTIVE` 是下一周期的起点而非永久放行。每次迁移都需要版本化输入、证据包、人工结论、R3 批准与幂等决策键。

## 2. 四层架构

| 层 | 职责 | 主责 | 必须交接/约束 |
| --- | --- | --- | --- |
| L1 战略层 | 年度品类规划、准入决策 | 企划 | 输出版本化品类策略、准入结论和年度目标。 |
| L2 计划层 | 季度/月度计划、坑位分配 | 企划 + 买手 | 只能使用已批准的策略、优先级与容量约束。 |
| L3 执行层 | 供给准备、供应商管理、运营优化 | 招商 + 买手 + 运营 | 通过各自域的控制面执行，回传只读证据。 |
| L4 保障层 | 品控能力、供应链履约、数据支撑、产品工具 | 品控 + 供应链计划 + BI + 产品 | 品控与履约有阻断/升级权；数据和工具不能把模拟结果变成业务结论。 |

## 3. T0 正式开放的 16 周倒排

| 时间 | 阶段/主责 | 输入 | 交接物与门槛 | 失败回退或升级 |
| --- | --- | --- | --- | --- |
| T-16~T-13 | 市场调研 / 企划 | 已批准分析口径、竞品来源、年度目标 | 年度品类计划三段式分析和竞品调研；每项须有数据截至和来源 | 缺少口径/来源则回到 `DRAFT`；争议提交季度准入评审。三段具体拆法待确认，不得虚构。 |
| T-14~T-10 | 招商启动 / 招商 | 目标品类与初步策略 | 目标商家摸底、供给储备启动、产地城市锁定 | 产地或商家数据不足则保留观察并升级周招商会。 |
| T-12~T-9 | 能力建设 / 品控+运营 | 风险品类需求、培训/实验室计划 | QC 实验室设备采购计划与运营卖货培训完成证据 | 任何关键 QC 能力未验收则 Quality 阻断后续认证与开放。 |
| T-10~T-7 | 供应商开发 / 招商 | 产地策略、供应商画像、准入规则 | 招商攻坚、初筛、资质审核和候选池 | 供应商数量、深度或质量卡口不足，留在供给准备并按升级规则处理。 |
| T-8~T-5 | 品控认证 / 品控 | 样品、材质/年龄/标准版本、实验室能力 | 寄样/检测报告和实验室能力验收 | 检测不合格、证据缺失或高风险品类触发 Quality 阻断、整改或退出。 |
| T-4~T-1 | 运营准备 / 买手+运营 | 已认证供给、策略、坑位与 F0 规则 | 小批量上线、商品分层、F0 爆品孵化预热 | 未满足 F0/成本/履约条件只能停留观察，不得自动开放。 |
| T0 | 正式上线/坑位开放 / 全部门 | 全部前置接收与只读验收 | 版本化开放决定、坑位开放记录与基线报告 | 任一阻断未清除，维持未开放或回退至对应准备阶段。 |

## 4. 固定会议与人工终态

| 节奏 | 主持/参会 | 输入与产出 | 人工终态 |
| --- | --- | --- | --- |
| 每月首个工作日月度品类会 | 企划主持；八大部门负责人 | 上月只读复盘、下月计划和资源冲突 | 批准、带条件批准、退回重做或升级。 |
| 每季度季度准入评审 | 企划主持；业务老板 + 八大部门 | 准入包、风险/阻断意见、关闭建议 | 新品类开放、维持观察、关闭/退出或待裁决。 |
| 每周三爆品评审会 | 买手主持；买手 + 运营 | F0 逆向排除/条件准入材料 | 进入观察、条件准入、退回补证或排除。 |
| 每周招商进度会 | 招商主持；招商 + 买手 + 企划 | 供给储备、产地策略、商家质量 | 继续、集中攻坚、切换策略、升级或暂停。 |

“八大部门”的具体名单与权限映射尚未提供；会议必须引用当期已登记的部门/责任人清单，不能由 Agent 猜测补齐。
