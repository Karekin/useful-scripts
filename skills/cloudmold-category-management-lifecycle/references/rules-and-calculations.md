# 规则、计算与人工升级

所有阈值、词典、观察窗口、指标口径、来源、适用租户和生效时间必须版本化。除明确标为“用户指定初版基线”外，规则只可作为人审或模拟输入，不能产生自动业务结论。

## 1. 准入与优先级

### 准入硬排除

任何一项命中即一票否决：

- 品牌高度聚集：Top10 品牌 GMV 占比 **>50%**。
- 复杂/非白牌标准化品类关键词：`定制`、`定做`、`设计`、`DIY`、`来料加工`、`来图`、`来样`、`量身`、`私人定制`。
- 叶子类目年 GMV 必须 **>1 亿元**；经营类目组合规模也须处于已批准的可管理范围。

“白牌适配”术语的具体定义仍待用户确认，不能自行扩展或解释上述词典。

### 六维 100 分模型

`总分 = 市场规模分 + 纺织分 + 季节适配分 + 卖法适配分 + 工艺简单分 − min(10, 退货率小数 × 20)`。

| 维度 | 分值/规则 |
| --- | --- |
| 市场规模 | 最高 40；分档映射待配置。 |
| 纺织加分 | 纺织 15，非纺织 0。 |
| 季节适配 | 明确旺季 7，全年型 10；其他情况待配置。 |
| 卖法适配 | 直播主导 7，直播搜索双驱 10，均衡 12，搜索主导 10，推荐主导 13。推荐主导高分为既定规则，不改写。 |
| 工艺简单 | 低复杂 10，中等 6，高复杂或高难度 3。 |
| 退货惩罚 | 最高扣 10。退货率必须以 0~1 小数传入（如 50%=0.50）；若来源为百分数，先除以 100，禁止混用。 |

等级：S `≥60`，A `40~59`，B `<40`。S：加成上限 30%、坑位权重 1.5、优先开放与旺季重点坑位；A：20%、1.2、正常开放；B：10%、0.8、观察期暂不开放。加成/权重只能用于模拟或转级预案，不能实际生效。

### 卖法分类

观察窗口和分子/分母可配置，阈值为 `≥30%`：直播与搜索均 `≥30%` 时优先归双驱；否则任一单渠道 `≥30%` 时取占比最高者；并列时按直播→搜索→推荐；全部 `<30%` 为均衡。分类需要数据截止日和分布证据。

## 2. 坑位、F0 与招商

### 月度日历与坑位

每日固定上新 1,300，固定 30 天月度坑位为 39,000。6~10 月每月环比 `+10%`：`M_t = round(M_(t-1) × 1.10)`，首月基数、取整和例外必须版本化。基础坑位按品类月度市场 GMV 份额分配，再叠加等级权重。

`GMV 预估 = 品类月坑位数 × 基础基准坑产 × 坑产系数`；基准坑产和系数必须携带来源、观察周期和版本。

月度重要级别：S=旺季且优先级 `≥60`（重点坑位保障）；A=旺季且 `40~59`（正常坑位）；C=淡季最小坑位。月度“B”建议为**另一套月度标签**：平季且优先级 `≥50` 的基础坑位，不能与六维等级 B(`<40`)混用；该建议待审批后才可生效。

### F0：逆向排除和条件准入

不固化未成熟正向预测。高退货 `>60%`：条件准入，需品控与入仓成本评估；强直播依赖（直播 `>30%`）：条件准入，需直播卖货能力评估。羽绒、皮草、真丝、皮衣默认不进 F0；礼服、晚装、汉服、旗袍等“13 类特殊场景”默认不进，完整 13 类词典尚未提供；当前类目名含“袜”调性不符，默认不进。所有词典可配置、可审计。

### 招商供给卡口

前 5 产地城市供给占比 `>50%` 为产地强聚集：线下地面团队集中拜访 Top5；`≤50%` 为分散：线上招商 + 区域代理。全部卡口须通过：供应商至少 10 家（可随商家密度版本化）、签约供应商可供商品数 `≥目标坑位×1.5`、签约供应商高潜池占比 `≥40%`。

## 3. QC、入仓与成本

### 材质/儿童安全

- 羽绒：蓬松度 `≥600FP` 且含绒量 `≥90%`；皮草须天然毛皮证明；真丝含量 `≥95%` 且有成分检测报告；皮衣为头层牛皮或羊皮。
- 童装、婴幼儿、亲子专项为极高风险强制拦截：保留报告、年龄与标准版本。当前基线记录为 GB 31701-2015：A 类甲醛 `≤20mg/kg`、B 类 `≤75mg/kg`、3 岁以下必须 A 类、7 岁以下禁止头颈部拉带、校服甲醛 `≤75mg/kg`。官方标准平台显示 GB 31701-2015 为强制性现行标准，2022-04-02 复审结论为继续有效；每次上线仍须按适用标准/版本复核，不能以本文件替代法规或检测。 [国家标准信息平台](https://std.samr.gov.cn/gb/search/gbDetailed?id=71F772D80590D3A7E05397BE0A0AB82A)

### 用户指定初版成本基线

正向入仓：1.60 元/件；单次质检：0.80 元/件、抽检 20%、均摊 0.16 元，故正向入仓合计 1.76 元/件。仓发：快递 2.10 元/单 + 包材 0.25 元/件 = 2.35 元/件。退货率基线 50%；逆向作业 1.06 元 + 退货包材 0.17 元 = 1.23 元/件。最低单件贡献毛利率 27%。

`贡献毛利率 = (确认收货成交价 − 最高入仓供价 − 单件仓发成本 − 预期退货处理成本) / 确认收货成交价 ≥27%`；`预期退货处理成本 = 退货率 × 1.23`；`最高入仓供价 = 确认收货成交价 × (1−27%) − 单件仓发成本 − 预期退货处理成本`。

该公式是用户指定初版基线。财务必须先确认“最高入仓供价”是否已含正向入仓 1.76 元；若不含，须以版本化规则把 1.76 元**仅扣减一次**。在此确认前不能做真实入仓开放或采购价格结论；不满足毛利率或加价倍率不可行即不开放入仓。

## 4. 八类人工升级

| 触发 | 时限/升级对象 | 人工终态 | Agent 冻结边界 |
| --- | --- | --- | --- |
| QC 合格率连续 3 周 `<90%` | 48h；Quality 负责人 + 品类审批人 | 放行整改、继续阻断或退出 | 不可解除 Quality 阻断。 |
| 爆款率环比下降 `≥10pp` | 48h；买手 + 运营 + 品类经理 | 调整计划、观察或暂停 | 不可改写 F0/坑位结论。 |
| 供应商履约率 `<80%` | 72h；招商 + 供应链计划 + 品类经理 | 整改、替换、暂停或退出 | 不可生成/变更供应商事实。 |
| 品类开放卡口未通过 | 当前活动周期；品类经理 + 责任域 | 补证、整改、延后或拒绝开放 | “当前活动周期”按月度计划时为当月，否则为当前开放周期；不得自动开关。 |
| 大促期 GMV 连续 3 日低于计划 50% | 24h；运营 + 买手 + 品类经理 | 纠偏、降级、暂停或继续观察 | 不可自动调配资源。 |
| 新品类准入争议 | 立即标 `PENDING_DECISION`；下季度评审裁决 | 开放、关闭、退回或待补证 | Agent 不得自行开关。 |
| 坑位分配争议 | 72h；买手 + 运营 + 品类审批人 | 重分配、维持或退回计划 | 不可直接写坑位。 |
| 供给储备不足 | 1 周；招商 + 买手 + 企划 | 集中攻坚、策略切换、延后或退出 | 不可虚构供给已满足。 |
