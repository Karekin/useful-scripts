# 电商品类日常运营

这是岗位级业务主流程，不是日报、技术巡检或单点方法调用。

每日由 Temporal 生成全新的品类经营场景，并在 R3 审批后执行：

1. 创建、通知并认领当日品类运营行动单。
2. 根据轮换问题场景形成诊断和行动组合。
3. 建立新的款式、SPU、SKU，完成刊登审核、发布和渠道回执。
4. 创建控制组与实验组，写入曝光、指标快照并形成显著性结论。
5. 执行目标人群活动触达，完成发送、送达、打开、点击和活动收尾。
6. 以独立消费者身份完成搜索、商详、收藏、加购、结算、支付履约、客服、售后和社区内容验证。
7. 只有四条业务链全部达到终态，才能关闭品类运营行动单并回读 `RESOLVED`。

每日场景会在低转化、高浏览低加购、活动失效和内容质量问题之间轮换。所有商品、刊登、实验、活动、订单和行为对象都使用本次 Temporal occurrence 生成的唯一标识。
